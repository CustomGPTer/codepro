What CodePro does not do

No app can run a dialer code by itself on Android, CodePro included: it opens your Phone app with the code ready. It has no lock-screen or account bypass. It is not on Google Play, so it does not update itself.

Where they do more

Secret Codes and Phone Test lists codes for Tecno and Infinix phones, which CodePro does not cover yet. Both install and update from Google Play.
